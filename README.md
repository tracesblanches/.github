# .github

Profil de l'organisation traceblanche sur GitHub et fichiers communautaires par défaut de ses dépôts.

- `profile/README.md` : la page de l'organisation, avec sa bannière claire et sombre (`profile/banner-*.svg`).
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md` : règles communes à tous les dépôts qui n'ont pas les leurs.
- `.github/ISSUE_TEMPLATE/` et `.github/pull_request_template.md` : modèles d'issues (bogue, idée, données ou site) et de demande de fusion.
- `assets/avatar.svg` et `assets/avatar.png` : l'image de l'organisation.

Le nom du projet est provisoire. `scripts/rename.sh NOUVEAU` le remplace dans tous les fichiers suivis.
